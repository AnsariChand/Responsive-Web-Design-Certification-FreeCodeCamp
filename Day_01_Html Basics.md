# Day-01\_ Introduction Html & CSS & JavaScript Basics

**1.** **Html** Stands for HyperText Markup Language. It's the code that defines the structure and content of a Webpage. for write the code you have a Code Editor.

**2.** **HTML** is made up of elements. The first one you will use is th H1 element. It starts with an opening tag (h1)

```
<h1>Welcome to  freecodecamp </h1>
```

**3.** An H1 element is the main heading of a webpage and you Should only use one per page. H2 Elements represent subheadings. You can have multiple per page and they look like this:

```
<h2> This is a Subheading </h2>
```

**4.** When you need to add a paragraph to a webpage, you can use the p element like this:

```
<p> This is  a paragraph element </p>
```

**5.** There are Six heading elements in HTML:
h1 through h6. They're used to show the importance of Sections on your Webpage, with h1 being the most important and h6 the least.

```
<h3> Introduction to Html </h3>
```

#### Notice that Each heading look a little different in the preview. Same with the paragraph

## Introduction to CSS

**6.** While Html defines the Structure and content of a Webpage, CSS is used to add style- Things like colors, fonts, spacing, and layout.

**7.** Finally, JavaScript makes your webpage interactive- it lets you tell the page what to do when someone clicks a button, submits a form, or many other things.
